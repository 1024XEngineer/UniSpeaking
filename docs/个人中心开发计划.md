# Personal Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有个人中心从前端 Mock 升级为真实的账号与设置中心，支持用户资料、头像、个人概览、可扩展成就、密码安全、长期资料隐私和 30 天延迟注销。

**Architecture:** 保持 Spring Boot 模块化单体。个人概览使用 `ProfileOverviewService` 编排练习统计、资产数量和成就服务公开的查询端口；账号、偏好和成就分别持有自己的数据，不在 `"user"` 表复制业务统计。前端继续复用现有设置组件，不调整页面布局。

**Tech Stack:** Java 21、Spring Boot 4、Spring Security OAuth2 Resource Server、MyBatis-Plus、PostgreSQL、React 19、Vite 6、对象存储。

## Global Constraints

- 开发分支固定为 `feature/profile-page`。
- 不修改其他模块已经开发完成的代码；必须修改时先向用户列出文件、原因和影响并取得授权。
- 只允许在 `docs/` 新增文档；新增业务文件和修改既有业务文件均按任务中的授权门执行。
- 每个较大的、可独立验证的修改单独提交。
- 现有 SQL 字段名保持不变；新增 SQL 使用 `snake_case`，Java/JSON 使用 `camelCase`。
- 用户头像放对象存储，数据库只保存 `avatar_object_key`。
- 修改密码后所有设备退出。
- 账户注销后保留 30 天并允许撤销。
- 会员、额度和支付保持现有演示逻辑。
- 不调整个人中心布局和响应式样式。
- 不增加缓存、消息队列或微服务。
